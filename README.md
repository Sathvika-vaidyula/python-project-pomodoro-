Python-Project-Pomodoro-Timer
A simple Python program that uses Tkinter to implement the Pomodoro productivity technique with work and break intervals.
__________________________________________________________________________________________________________________________________
HOW IT WORKS

Work: Runs a 25-minute work session.

Short Break: After each work session, triggers a 5-minute short break.

Long Break: After 4 work sessions, triggers a 20-minute long break.

Progress: Displays check marks (✓) to track completed work sessions.

Reset: Stops the timer and resets all progress.
____________________________________________________________________________________________________________________________________
USAGE
Run the script:
python pomodoro_timer.py
Click Start to begin the timer.

The label will change to show whether it's work time or break time.

Click Reset anytime to stop and clear the timer.
_______________________________________________________________________________________________________________________________
EXAMPLE

Start the timer → Label shows "Work" with countdown 25:00.

After 25 minutes → Label changes to "Short Break" with 5:00.

After 4 cycles → A "Long Break" of 20:00 starts.

✓ marks appear after each work session.
